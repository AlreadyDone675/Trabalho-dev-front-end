# 🛠️ ServiceTech

Sistema web de gerenciamento e acompanhamento de chamados para assistência técnica de eletrônicos, desenvolvido para resolver o problema de controle de atendimentos de uma empresa de assistencia tecnica, facilitando a vida do cliente e agilizando os atendimentos **Desenvolvimento Front-End**.

---

## 📄 Páginas do Projeto

- **Início (`index.html`)** — Landing page com apresentação dos serviços e consulta rápida de chamado por número.
- **Acompanhamento (`registro-status/registro-status.html`)** — Detalhes do chamado, linha do tempo e previsão de retirada para o cliente.
- **Login (`login/login.html`)** — Tela de acesso administrativo.
- **Painel de Controle (`painel-controle/painel-controle.html`)** — Quadro Kanban com indicadores, prazos e cadastro de novos atendimentos.
- **Status de Atendimentos (`status-atendimento/status-atendimentos.html`)** — Tabela geral com filtro por status, busca por ID/cliente e edição rápida de status.
